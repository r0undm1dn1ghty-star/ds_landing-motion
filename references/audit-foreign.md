# Аудит чужого лендинга: DOM-пробник и пороги

Зачем: `self-audit-loop.md` меряет СВОЮ сборку (гейт `measure.py`). Здесь — механический аудит ЧУЖОЙ живой страницы: числа из DOM вместо «выглядит устаревше». Пороги выведены на реальном прогоне пяти сайтов мебельных фабрик и клиник (2026-11-04, отчёт: `hermes_work/ds_landing-motion-launch/audit-5-лендингов-2026-11-04.md`).

## Пробник (один вызов в консоли живой страницы)

```js
(() => {
  const t = s => [...document.querySelectorAll(s)].length;
  const vis = [...document.querySelectorAll('h1,h2,p,span,a,div')].filter(e=>e.offsetParent!==null).slice(0,3000);
  const fs = {}; vis.forEach(e=>{const s=getComputedStyle(e).fontSize; fs[s]=(fs[s]||0)+1;});
  return {
    h1: [...document.querySelectorAll('h1')].map(h=>h.textContent.trim().slice(0,90)),
    h2: t('h2'), sections: t('section'), imgs: t('img'),
    buttons: t('button, .btn, [class*=button], [class*=btn]'),
    animations: document.getAnimations().length,          // замерить 3 раза с шагом 3с: рост = бесконечные циклы
    transitions: [...document.querySelectorAll('*')].filter(e=>getComputedStyle(e).transitionDuration!=='0s').length,
    htmlKB: Math.round(document.documentElement.outerHTML.length/1024),
    fontSizes: Object.entries(fs).sort((a,b)=>b[1]-a[1]).slice(0,5)
  };
})()
```

Плюс: скриншот первого экрана (глаз = след, подтверждать числами) и проба текста на копирайт-детекторы из `design-read.md` (канцелярит, самоописания вместо фактов, «Качественно. Недорого. Быстро», восклицания пачками).

## Пороги (число → вердикт)

| Замер | Порог | Вердикт |
|---|---|---|
| H1 | > 1 | SEO-слоп; норма — один заголовок с числом |
| H1 + H2 | оба 0 | у страницы нет структуры: человек и поисковик не понимают, о чём она |
| Активные анимации (`getAnimations`) | > 30 и не падает за 3 замера | анимационный шторм: вечные циклы без причины; канон — движение отвечает «что это показывает» |
| Анимации + переходы | 0 и 0 | мёртвое лицо; для продающего лендинга — потеря |
| Основной шрифт (мода по видимым элементам) | < 14px | мёртвая типографика; body ≥ 14px, комфорт 16+ |
| Переходы без анимаций (много `transition`, 0 движений) | переходы > 100, анимации 0 | микроперемешивание вместо движения: ховер есть, истории нет |
| HTML | > 400 КБ без сборки | простыня: секции не выстроены, всё свалено |
| Секции | > 20 на лендинге услуг | рассказ превращён в каталог |
| Ссылка из рекламы/выдачи | 404 / редирект на главную | реклама в пустоту — фиксится за вечер, разбирается отдельно и уважительно |
| Фото | сток/3D-визуализации там, где заявлено производство | сильнейшее доказательство (свой цех, станок, готовая работа) не показано |

## Порядок разбора

1. Пробник → таблица чисел. 2. Копирайт-детекторы по тексту. 3. Скриншот + vision (наш vision 401 → Ollama `gemma4:31b`, см. скилл `ollama-cloud-vision`). 4. Вердикт по той же шкале, что и своя сборка: что показывает, что нет. 5. Три правила починки максимум — не план редизайна.

## Этика публичного разбора

Разбор с именем — только с уважением: имя + что живого и настоящего + что чинить числами. Без имени — если фикс не про уважение (мёртвая ссылка, кривая разметка цены). Класс текста — «сигнал/разбор» по `discovery-content-voice`: решение-слой обязателен, продажи нет.
