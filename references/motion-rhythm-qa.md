# Ритм движения: числами, а не глазами

Статичный кадр не показывает тайминг. По картинке нельзя понять, есть ли в середине секундная дыра, где всё замерло, и не мигает ли что-то двадцать раз в секунду. Это измеряется, и мерилка уже лежит в скилле. Источник — `frankenstein-animator` (Claude), скрипт перенесён как есть.

## Что мерим

`scripts/motion_qa.py` берёт видео (или запись прокрутки), сжимает кадры до 64×36 в серый, считает **разницу между соседними кадрами** и выдаёт три факта:

| Метрика | Что ловит | Порог по умолчанию |
|---|---|---|
| **Мёртвая зона** | застой: экран не меняется дольше N секунд | ≥ 0.75 с при разнице < 0.05 |
| **Всплеск** | резкий скачок: поп, глитч, жёсткий рез | > 4× медианы ненулевых |
| **Затухание** | энергия последней четверти к первой: «выдохся под конец» | отношение, меньшее — признак |

```bash
python scripts/motion_qa.py in.mp4                 # печатает шкалу энергии, дыры, всплески
python scripts/motion_qa.py in.mp4 --json          # машиночитаемо
python scripts/motion_qa.py in.mp4 --dead-sec 0.5 # свой порог застоя
```

Скрипт **сообщает факты, а не приговор**: дыра может быть задумана (пауза перед ударом), всплеск — быть резом по биту. Сначала числа, потом решение.

## Правило, которое экономит круги

**Чистый код выхода ≠ качество.** Скрипт без находок не значит «смотреть не надо». Порядок всегда: числа → кадр глазами → суждение против замысла.

## Восемь рычагов «норм» против «охуенно»

Оценивать каждый по 1–5 после каждой сборки и **чинить сначала самый слабый**. Это оценка автора, а не измерение — так и подавать.

1. **Easing.** Линейного движения нет, кроме осознанного (тикер, спиннер). Вход — пружина с перерегулированием, перемещение — ease-in-out. У нас допустимы только ease-out-кварт/квинт/экспо (см. `anti-slop-design`).
2. **Стаггер и перекрытие.** Элементы стартуют через 2–6 кадров, не одновременно. Есть доводка: после главного движения элемент «доседает».
3. **Ритм-грамматика.** Одна битовая единица на всю страницу и её переиспользование. Резы/смены — по битам.
4. **Камера.** Медленный наезд, слои параллакса, лёгкий поворот. Статичная камера читается как слайды.
5. **Типографика.** 1–2 семейства, сильный контраст масштаба, контраст текста ≥ 4.5:1 к своему фону.
6. **Палитра.** ≤ 5 цветов, один акцент. Постоянство важнее разнообразия.
7. **Отделка.** Зерно, виньетка, мягкая тень, световая засветка, смаз. Тихо. Отделка не спасает пустую секцию.
8. **Сдержанность.** Один герой-момент на бит. Мёртвая зона — только если задумана.

## Цикл критики: максимум 3 круга, потом сдавать

1. Кадры → смотреть композицию, иерархию, цвет, обрезку.
2. `motion_qa.py` → числа по застою, всплескам, затуханию. Каждую находку объяснить или починить.
3. Оценить 8 рычагов, назвать слабейший, **поменять ОДНУ вещь**, пересобрать короткий участок, а не всё.
4. Стоп, когда ни один рычаг < 3 или после 3 кругов. Оценки отдать как свою оценку.

## Как это переносится на лендинг

Ролик и страница меряются одним прибором, меняются слова:

- **мёртвая зона** → участок секции, где движение должно быть, а его нет (длинный текст без единого момента);
- **всплеск** → поп, глитч, скачок шрифта, мигание при появлении;
- **затухание** → страница выдыхается к концу: низ лендинга статичен, хотя верх живой.

Для страницы снимается запись прокрутки (или покадровые скриншоты при `scroll` с фиксированным шагом) — дальше тот же скрипт.
